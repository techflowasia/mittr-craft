## Findings

1. **F1.** Prod MittrCraft 1.22 (PID 2848) exited at 23:45:15 during Part A.
   - No signal was sent to it.
   - Its last log line is a terminated message-stream proxy.
   - Engine 3624 is left running with ppid 1.
   - It overlapped the upstream web test stage, which ran under the real HOME (F2).
   - The owner should reopen the app.
2. **F2.** `test-baseline.mjs` runs upstream suites under the real HOME. They write `~/.local/share/opencode/worktree/*` and `~/.config/openchamber/*`. Proposal: give each stage a temp `HOME` and `XDG_*`.
3. **F3.** During Part A, someone answered the test window: the connect confirm twice, and "Sign in with Mittr" three times (the browser opened the loopback stub URL). The effects stayed inside the temp `userData`. Part B should confirm that a host switch never starts sign-in by itself.
4. **F4.** `mittrcraft --help` prints upstream's usage text, naming OpenChamber and OpenCode.
5. **F5.** The sign-in and "Try again" buttons render in lower case (upstream button style). Check in the walk.
6. **F6.** With one of two agents used up, the session panel shows weekly usage "100%" in red. Check its meaning in the quota walk.
7. **Carry.** The sidebar shows "Could not initialize workspace." on a temp HOME. Re-check with a real project folder in Part B.
8. **F7 (Important; fixed, re-walk PASS: no third-party quota provider is listed, and no `security` process ran).** One upstream quota provider (`packages/web/server/lib/quota/providers/` for a third-party coding assistant) reads that tool's login-keychain item and calls the vendor's usage API with it. The tester's own probe made one such call. Proposal: hide upstream's third-party quota providers in the product (R30/R39).
9. **F8 (fixed in the app; re-walk PASS).** The platform keys `/api/quota/me` `agentStatus` by Studio agent, while the app looks up the desktop alias. Picker marks therefore never show (P2-09).
10. **F9 (fixed; re-walk PASS, the platform now answers `agent_not_granted`).** A withdrawn alias gets 403 `desktop_entitlement_required` from the platform. The app expects `agent_not_granted` for that case (P2-14).
11. **F10.** The engine prefers the `rg` on the login-shell PATH. A machine with no system `rg` is still unproven.
12. **F11 (fixed; re-walk PASS).** Usage listed internal platform names, such as "System decision model (Jev)". It now shows only the MittrCraft names plus speech. The group heading still reads "Other Models".
13. **F12.** With the switch ON, the engine adds local Ollama models.
14. **F13.** The admin's MittrCraft tick can save without reaching the platform key; re-saving fixed it.
15. **F14.** Upstream CLI `session send --wait` hangs when a turn fails.
16. **F15.** GitHub `/user/emails` returns 404 on every launch.
17. **F16.** Buttons render in lower case, and "Show response details" shows raw JSON.
18. **F17.** "Weekly 100%" shows in red once one agent is used up.
19. **F18.** An orphaned Dev 1.x engine, PID 90437, holds `~/.config/mittrcraft-dev` open.
20. **F19.** The dev default weekly limit changed during the gate, not by the test.
21. **F-C1 (Important, security).** On hosted web the engine inherits every `MITTR_AD_*` variable, `MITTR_AD_CLIENT_SECRET` included (checked by name with `ps eww`). An agent shell command could read the company app's secret; with LDAP, the bind password. Proposal: strip `MITTR_AD_*` from the engine environment, and add a test for it.
22. **F-C2.** The hosted web tab title is "OpenChamber - AI Coding Assistant". `packages/web/dist/index.html` keeps upstream's title; only the desktop `resources/web-dist` is patched.
23. **F-C3.** `bin/mittrcraft.mjs` applies only the `MITTRCRAFT_BROKER_*` keys of `product-env.json`. Without the other keys, a packed hosted server:
    - answers update checks by calling `api.openchamber.dev`;
    - fetches models.dev metadata;
    - writes upstream's `~/.config/openchamber/managed-opencode` (seen in this run).

    The first two come from reading the code; this run switched them off by hand. Owner call: apply the whole product env in the bin.
