# Feature parity: MittrCraft 1.22 against the 2.1.1 re-fork

Date: 2026-10-25
Status: read-only audit. Nothing was built, launched, edited or committed. The only command run in this tree was `node scripts/mittr/check-upstream-touch.mjs --no-write`.

- **1.22:** `.worktrees/team-build`, branch `build/1.22.0-team` at `2f800efd3`. Same content as `origin/develop` (`be34959cb` is only the merge of it). Fork point from upstream: `c6772a636` (1.18.4). There are 165 Mittr commits.
- **2.1.1:** `.worktrees/today-glass`, branch `feat/today-glass` at `2a103c4d3`.
- **Upstream touch:** **38 of 40** (check passed). There are 2 counted files left.

## How this was done

I did not start from the inventory. I built the list of what a person can see from 1.22 itself:

1. I reversed the OpenChamber→MittrCraft rename in the 1.22 sources and diffed them against upstream 1.18.4 under `packages/ui/src`, `packages/web/server`, `packages/web/bin` and `packages/electron`.
   - This gave 186 upstream files with real edits and 108 added files.
   - I classified every file. Most edits are only renames or the removal of opacity tiers.
2. I listed every Mittr route the 1.22 server registers (`/api/mittr/*`, `/api/mittrcraft/*`, `/api/voice/*`, `/auth/ad/*`) and matched each one in `packages/mittr-server/src`.
3. I compared the Settings pages (`lib/settings/metadata.ts` slugs) and every settings-search id between 1.22 and 2.1.1.
4. I read every Mittr settings section, sidebar header and footer item, composer action, message footer, dialog and keyboard binding in 1.22. I then found its counterpart in `packages/mittr-ui` (the slot registry in `product-ui-plugin.tsx`, `sidebarFooter.ts` and `integrationsPage.ts`) or in upstream 2.1.1.
5. I checked owner decisions in the following:
   - `docs/specs/2026-10-16-upstream-rebase-design.md` §10;
   - the phase 3, 4A and 4B gate and plan "Owner decisions" sections;
   - `docs/plans/2026-10-22-today-glass-design.md`.

Paths below are relative to each tree's root. "1.22" means `team-build`, and "new" means `today-glass`.

## 5. NOT CHECKED

- **Anything at run time.** The audit was read-only, so nothing was launched. Every row above is from code and the gate notes. That includes the tray glyph, macOS notification titles, Mini Chat's sign-in gate, the About version string, and Settings search results shown in the window.
- **Whether 1.22 also hid waiting Chrome cards behind other views (C3).** That would need a 1.22 walk.
- **Whether anyone on the team uses an Intel Mac (MISSING 10).**
- **Hosted-web AD/Entra and the CLI `serve`.** The code is present (`packages/mittr-server/src/ui-auth/*`, `/auth/ad/callback`). It was not run here; the phase 2 gate Part C covers it.
- **Plane multi-workspace against a real account.** The owner has no Plane account (phase 3 finding 27). It was proven only on the stub.
- **Speech-quota rows on dev (P4-V2, P4-V9).** They stay NOT RUN unless account Q's quota is lowered (4B gate).
- **Schedules defaulting to Etc/UTC (4A B10-1).** This may be caused by the gate's `env -i`; a normal launch was not checked.
- **Per-account data carry-over for a second account's 1.22 history.** The phase 1 and phase 2 gates claim it; it was not re-proven here.
- **The VS Code and mobile packages.** They are deferred, so they were not inspected.
- **Non-English locales.** Mittr strings are English-only in both builds. I did not check whether any upstream key shows raw in another locale.
- **Upstream 1.18.4 → 2.1.1 removals beyond the settings-search ids and settings slugs compared here.** For example, message actions and dialogs that upstream itself changed. Upstream-internal refactors were left out by design.
