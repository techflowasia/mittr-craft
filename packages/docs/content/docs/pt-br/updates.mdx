# Atualizações

Como você atualiza o MittrCraft depende de como o instalou. Em todos os casos, você pode verificar sua versão atual em **Settings → MittrCraft → About**.

## App de desktop

O app de desktop verifica atualizações nas releases do GitHub. Quando há uma disponível, o MittrCraft avisa você, baixa-a quando você escolhe e a instala no próximo reinício. Você está sempre no controle — nada é instalado sem a sua autorização.

## Web / CLI

Se você instalou a CLI, atualize-a a partir de **About** com os botões de verificar e atualizar, ou pelo terminal:

```bash
mittrcraft update
```

O MittrCraft detecta como foi instalado (npm, pnpm, yarn ou bun) e executa a atualização certa para você.

## O servidor OpenCode

O MittrCraft e o OpenCode são atualizados separadamente. Quando uma nova versão do OpenCode está disponível, o MittrCraft oferece atualizá-la e reinicia o servidor em seguida. Veja [OpenCode Server](/pt-br/opencode-server/) para como esse servidor é gerenciado.
